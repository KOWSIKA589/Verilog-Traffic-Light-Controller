# Verilog Traffic Light Controller

A **Traffic Light Controller** designed and implemented using **Verilog HDL** using a **Finite State Machine (FSM)**.

## 📌 Overview

This project implements a basic traffic light controller that controls traffic signals according to predefined states and timing sequences.

The controller uses sequential logic and FSM concepts to transition between different traffic signal states.

## 🚦 Features

* FSM-based traffic control
* Red, Yellow, and Green signal control
* State transition logic
* Clock-based operation
* Reset functionality
* Simulation waveform verification

## 📂 Project Contents

The project contains:

* Verilog source code
* Testbench
* FSM/state diagram
* Simulation waveform
* Output

## 🧠 Design Concepts

The project demonstrates:

* Finite State Machine design
* State transition logic
* Sequential and combinational logic
* Clock and reset signals
* RTL implementation

* HDL Simulation Tool
* EDA Playground/Vivado
